# Монополия

Браузерная многопользовательская «Монополия». Бэкенд — Java 25 + Spring Boot, клиент — чистый HTML/JS
(отдаётся самим Spring Boot, Node.js не нужен). Связь — WebSocket (`/ws`), JSON-сообщения.

## Запуск

Нужна JDK 25 (например, Eclipse Temurin 25: `winget install --id EclipseAdoptium.Temurin.25.JDK`).
Maven ставить не нужно — его скачает `mvnw`.

```bash
./mvnw spring-boot:run
```

Для правки фронтенда удобнее профиль `dev`: html/css/js берутся прямо из `src/main/resources/static`,
изменения видны после обновления страницы (Ctrl+F5), без перезапуска:

```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

Откройте http://localhost:8080 в двух вкладках: в одной создайте комнату, в другой войдите по коду.

Тесты правил:

```bash
./mvnw test
```

## Структура

```
src/main/java/com/example/monopoly/
  engine/   чистые правила игры, без Spring (Game, Board, Player, Tile, TurnPhase, Dice)
  lobby/    комнаты в памяти, сериализация команд по комнате
  ws/       WebSocket-эндпоинт и протокол
src/main/resources/static/   клиент (index.html, app.js, style.css)
src/test/java/.../engine/    тесты правил с детерминированными кубиками (FixedDice)
```

## Протокол

Клиент → сервер: `{"type": "CREATE", "name": "..."}`, `{"type": "JOIN", "roomId": "...", "name": "..."}`,
`{"type": "RESUME", "roomId": "...", "token": "..."}`,
`START`, `ROLL`, `BUY`, `DECLINE`, `CLOSE_CARD`, `PAY_DUE`, `PAY_JAIL_FINE`, `USE_JAIL_CARD`,
`{"type": "BID", "amount": 50}`, `PASS`,
`{"type": "BUILD", "tileIndex": 3}`, `{"type": "SELL_HOUSE", "tileIndex": 3}`,
`{"type": "MORTGAGE", "tileIndex": 3}`, `{"type": "UNMORTGAGE", "tileIndex": 3}`,
`PAY_DEBT`, `DECLARE_BANKRUPTCY`,
`{"type": "PROPOSE_TRADE", "trade": {"toId": "...", "giveTiles": [5], "takeTiles": [18], "giveMoney": 50,
"takeMoney": 0, "giveJailCards": 0, "takeJailCards": 0}}`, `ACCEPT_TRADE`, `REJECT_TRADE`, `CANCEL_TRADE`, `END_TURN`.

Сервер → клиент: `WELCOME` (ваш playerId и секретный token для возвращения), `LOBBY` (список игроков
до старта), `STATE` (полное состояние игры), `LOBBY` и `STATE` содержат `online` — кто подключён,
`ERROR` (только отправителю), `RESUME_FAILED` (вернуться не удалось — партии больше нет).
Соединение, вытесненное новой вкладкой того же игрока, закрывается с кодом 4000.

## Что уже работает

- поле из 40 клеток, бросок, движение, $200 за «Старт»
- покупка улиц, железных дорог, предприятий
- аренда: двойная при полной цветовой группе, ж/д 25/50/100/200, предприятия 4× / 10× кубиков;
  при попадании на чужую клетку аренда показывается всем и списывается, когда игрок нажмёт «Заплатить»
- налоги (как и аренда — окно с суммой и кнопкой «Оплатить»), «Отправляйтесь в тюрьму», три дубля подряд → тюрьма
- выход из тюрьмы: дубль, штраф $50, принудительный штраф на третьей попытке
- повторный бросок при дубле
- аукцион, если игрок отказался от покупки или ему не хватает денег
- дома и отели: только на собранной группе, равномерная застройка и продажа, лимит банка 32 дома / 12 отелей,
  продажа за полцены; карточки «ремонт» считают постройки
- залог за полцены и выкуп с 10%; заложенная клетка не приносит аренду, в её группе нельзя строить;
  при нехватке денег на покупку можно заложить имущество и купить
- карточки «Шанс» и «Общественная казна» (по 16, классические), карточка «Освободиться из тюрьмы»;
  вытянутая карточка сначала открывается всем и выполняется, когда игрок её закроет
- долги: если наличных не хватает, игрок сам продаёт дома и закладывает имущество, затем платит
  или объявляет банкротство; если не покрыть даже всем имуществом — всем показывается карточка «Банкрот»,
  банкротство выполняется по кнопке «Банкрот»
- банкротство: имущество уходит кредитору (банку — без залогов), определение победителя
- обмен между игроками: клетки, деньги, карточки «Освободиться из тюрьмы»; предлагает текущий игрок
  в свой ход, адресат принимает или отклоняет; за полученную заложенную клетку — 10% банку
  в окне обмена видны цены клеток и итог каждой стороны (клетки по цене + деньги + карточки по $50);
  обмен запрещён, если одна сторона стоит в 2 раза больше другой или больше (в т.ч. «подарки»)
- ограничения времени: 3 минуты на ход (потом ход доигрывается автоматически), 1 минута на ответ
  на обмен (часы хода в это время стоят; молчание — отказ), не больше 3 предложений обмена за ход,
  30 секунд на ставку в аукционе (молчание — пас), 1 минута на долг не в свой ход
  (потом автоматическая продажа построек и залог); сроки — константы в `Game`
- переподключение: после обрыва, перезагрузки или повторного открытия вкладки игрок возвращается
  на своё место (токен хранится в браузере); другие видят, кто «не в сети»
